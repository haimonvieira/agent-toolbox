# saa-orchestrator

## Descrição declarada

Sistema Agente Autônomo que orquestra o ciclo Executor→Crítico→Otimizador e delega para Multi-Agentes especializados. Use quando receber tarefas que exijam especialização, múltiplas perspectivas, ou orquestração de agentes. Modelo preferenciais: NVIDIA + KILO; Gemini só 2.5 Flash; free via SAA_USE_FREE=1.
