# web-search

## Descrição declarada

General web search skill that uses browser automation with multiple search engines and selects the priority chain based on search intent. Supports: Perplexity, Metaso AI, Google, Bing, Brave, DuckDuckGo, Baidu, Sogou, Tavily. Trigger when the user mentions "web search," "search for it," "search this for me," "look it up online," "search engine," or needs real-time information from the internet.
