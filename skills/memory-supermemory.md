# memory-supermemory

## Descrição declarada

Backend adapter for Basic Memory skills (memory-notes, memory-tasks, memory-schema, memory-ingest, memory-reflect, memory-defrag) that stores all data in Supermemory cloud via MCP. Replaces local filesystem storage with semantic search, graph memory, and cross-device sync. Use when you want memory-* skills to persist to Supermemory instead of /var/minis/memory/.
