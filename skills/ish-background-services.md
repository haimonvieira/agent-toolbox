# ish-background-services

## Descrição declarada

Start, inspect, stop and restart long-running background services on iSH (Alpine aarch64) — node servers, python http.server, watchers — and diagnose the "port already in use" / "my server won't stop" / "the change didn't take effect because the old process is still running" class of problems. Use this skill whenever you launch a local dev/preview server on this device, when a port is occupied, when a restart seems ignored, or when `pkill` appears to do nothing. Trigger even if the user only says "restart the app" or "the page still shows the old version".
