# browser-batch

## Descrição declarada

Accelerate browser automation in the iSH/Minis environment by batching multiple browser actions into a single shell round-trip via the minis-browser-use CLI, instead of one browser_use tool call per action. Covers the performance trade-off, error handling, session-wedge prevention, and recovery. Trigger when browser automation feels slow, when the user complains about response time, or when writing multi-step web flows.
