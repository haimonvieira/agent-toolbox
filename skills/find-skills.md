# find-skills

## Descrição declarada

Helps users discover and install agent skills when they ask questions like "how do I do X", "find a skill for X", "is there a skill that can...", or express interest in extending capabilities. This skill should be used when the user is looking for functionality that might exist as an installable skill. Searches the omgskills public catalog (55k+ skills) via MCP, checks the skills.sh leaderboard, and evaluates quality before recommending.
