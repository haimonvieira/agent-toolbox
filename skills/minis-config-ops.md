# minis-config-ops

## Descrição declarada

Read, bulk-edit, verify and revert Minis app settings from the shell with the `minis-config` CLI — sub agent instructions, providers, models, defaults, environment-adjacent fields, soul body. Use this skill whenever a task means "change Minis settings", "edit the sub agent instructions", "add a provider", "apply this to all N agents/entries", "make the same change across every model", "revert that config change", or whenever you would otherwise tell the user to tap through Settings. Also use it before ANY bulk config write, because the write payload is JSON-encoded-inside-JSON and the naive version fails.
