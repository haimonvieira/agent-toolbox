# find-skills

Categoria: Escrever e encontrar skills. Classificação: essencial.

## Por que está aqui

Pesquisa catálogos de skills por palavra-chave e devolve candidatos com install count e origem. É o que roda quando peço 'acha uma skill para X'. Neste ambiente foi estendida para consultar o omgskills via MCP como fonte primária.

## Origem

Instalada neste ambiente. Não há upstream confirmável: circulam cópias do
mesmo texto em vários repositórios e o original não pôde ser localizado.

Caminho: `skills/find-skills/`

## Instalar

Incluída em `mine/` neste repositório. Copie para o diretório de skills do
seu agente.
