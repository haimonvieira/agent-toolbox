# skill-creator

Servidor MCP via stdio. Estado atual: ativo.

## Registrar

```bash
minis-mcp-cli add --name skill-creator --command python3 --args "/var/minis/skills/skill-creator/mcp/skill-server.py"
```

## Nota

Servidor MCP para criar, validar, testar e gerir skills de agentes de IA

## Verificar

```bash
minis-mcp-cli ping skill-creator
minis-mcp-cli tools skill-creator
```
