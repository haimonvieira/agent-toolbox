# omgskills

Servidor MCP via http. Estado atual: ativo.

## Registrar

```bash
minis-mcp-cli add --name omgskills --url "https://omgskills.com/mcp"
```

## Nota

Catálogo público read-only de skills de agentes (55k+). Ferramentas: search_skills, get_skill, get_skills, list_trending, list_gold_basket, list_by_author. Instalável apenas quando pinned_install existe.

## Verificar

```bash
minis-mcp-cli ping omgskills
minis-mcp-cli tools omgskills
```
