# Local state

- `baseline.yaml` — sanitized, reviewed snapshot committed to the repository.
- `current.yaml` — generated by `./scripts/audit.sh`; **gitignored**.
- `../.local-state/` — machine-local cache and optional private terms; gitignored.

The baseline contains metadata only. Managed-skill names are redacted, and no credential values are
stored. Do not commit raw snapshots that contain private identifiers.
